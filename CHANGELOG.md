# Changelog

Короткие итоги заметных изменений. Новое сверху. Не дневник агента: что изменилось и почему, без пересказа сессии.

Формат записи: `### <Тип> (<тема>)`, где тип — Added / Changed / Fixed / Removed / Decision.
В конце записи — агент и ветка, если запись сделал агент.
