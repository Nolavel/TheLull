# Changelog

Короткие итоги заметных изменений. Новое сверху. Не дневник агента: что изменилось и почему, без пересказа сессии.

Формат записи: `### <Тип> (<тема>)`, где тип — Added / Changed / Fixed / Removed / Decision.
В конце записи — агент и ветка, если запись сделал агент.

### Added (лаборатория игрового опыта, v0)

- `lab/`: общий инструмент агентов без Unreal (Python 3, только stdlib). Мир-граф `district_v0` с вариантами
  `A_safe` / `B_readable` / `C_unreadable`; агент с ограниченным знанием мира, который учится на расхождении
  прогноза и факта; дневные истории решений и сводка (ошибка прогноза, запас времени, смены плана, испуги).
- Разделение ролей: Claude — мир и поведение, Codex — модель игрового опыта, автор — идентичность.
- Проверено: 4 теста, воспроизводимость по seed. Числа мира — заглушки, не баланс.

— Claude, `ue-claudeflow`

### Changed (общая политика GitHub и резервных копий)

- `AGENTS.md`: правило для облачной и локальной сессии одного агента в одной ветке; раздел «Где живёт проект» —
  GitHub (согласованное состояние), рабочий HDD (локальные изменения), Google Drive (только резервные копии,
  без двусторонней синхронизации и без автоматического восстановления).
- `docs/setup/LOCAL_UE.md`: процедура резервного копирования и ручного восстановления.
- `tools/backup.ps1`: отказ при открытом редакторе, проверка архива, копия в Drive со сверкой SHA-256,
  хранение последних 5 архивов. Не запускался: в облаке нет Windows.
- `CLAUDE.md`: ссылки на общие правила. `CODEX.md` уже ссылается на `AGENTS.md`, не менялся.

— Claude, `ue-claudeflow`

### Decision (хранение проекта)

- `H:\TheLull` (внешний HDD) — рабочий проект и клон репозитория; GitHub — код, конфиги, Blueprints, карты и
  небольшие ассеты (без LFS, файлы до 50 МБ); Google Drive `TheLull/Backups/` (бесплатные 15 ГБ) — датированные
  полные архивы. Движок и генерируемые папки не хранятся нигде. Рабочую папку с Drive не синхронизировать.
- Проект TheLull создаётся сразу (Blank Blueprint, без Starter Content) в корне репозитория; `UE_Lab` отменён.
- `tools/backup.ps1` — архив проекта без генерируемых папок; `.gitattributes` помечает ассеты бинарными;
  `Content/` больше не исключён в `.gitignore`.

— Claude, `ue-claudeflow` (по решению автора)

### Decision (рамки работы на текущем ноутбуке)

- Железо не покупаем до нового мощного ноутбука; на 4 ГБ RAM / Intel HD 620 сначала измерения.
- Без тяжёлых шейдеров и графики: работаем в узком пространстве геймплея. Референсы — Hoarbound,
  The Long Dark и ALIS (World Reborn, `fallintodusk/alis`) как открытый проект для изучения архитектуры, не для копирования; цель — production-шаблон, который потом масштабируется на мощном железе.

— Claude, `ue-claudeflow` (по решению автора)

### Added (локальная установка UE 5.8)

- `docs/setup/LOCAL_UE.md` (черновик): первый запуск UE 5.8.4 на ноутбуке — тестовый `UE_Lab` вне репозитория,
  DDC (Zen) на внешнем диске с учётом приоритета `UE-ZenDataPath`, без автоудаления кэша, настройки под Intel HD 620,
  подключение Claude Code через Unreal MCP. Запуск пустого редактора на 4 ГБ — эксперимент ради данных;
  зависание оценивается по активности CPU/диска/памяти, а не по таймеру.
- `.gitignore` для UE; `Content/` исключён: ассеты пока локально с резервной копией, Git LFS не используется.
- Облачное окружение `ue_claudeflow`: setup-скрипт ставит Blender 5.2.4 LTS.

— Claude, `ue-claudeflow`

### Added (правила агентов)

- `AGENTS.md`: одна постоянная ветка на агента с префиксом `ue-` (`ue-claudeflow`, `ue-codex`, `ue-grok`);
  commit и push в свою ветку — сам агент; PR, merge в `production` и чужие ветки — только с разрешения автора;
  синхронизация с `production` перед задачей (fast-forward, иначе merge, не rebase); проверка перед push
  (репозиторий публичный); воспроизводимость обязательна для изменений, тестов и сборок, не для исследования;
  взаимодействие агентов, дисциплина документации, честность отчёта.
- `CLAUDE.md`: роль технического директора, порядок работы над задачей, критерии «готово».
- `CHANGELOG.md`: этот файл.

— Claude, `ue-claudeflow`
