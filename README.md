# TheLull

Открытый продуктовый проект. Пока это исследовательская площадка будущей игры TheLull на Unreal Engine 5. Пока здесь нет игры: мы изучаем
архитектурные решения Epic и открытых проектов, принимаем решения и постепенно собираем production template.

- Движок: стабильная UE5. Версию фиксируем летом 2027 года после практической проверки на новом железе.
- Предварительный релиз: конец 2029 — начало 2030 года.
- Совместимость с UE6 не является критерием оценки решений.

## Где что лежит

- `docs/research/INDEX.md` — все карточки: статус, решение, дата.
- `docs/research/cards/` — карточки паттернов, по одной на вопрос (шаблон: `_template.md`).
- `docs/research/sources.md` — изученные проекты и документы: ссылка, версия движка, лицензия.
