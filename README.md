# TheLull

Открытый продуктовый проект. Сейчас это исследовательская площадка будущей игры TheLull
на Unreal Engine 5. Игры здесь пока нет: мы изучаем архитектурные решения Epic и открытых проектов, принимаем решения и постепенно собираем production template.

- Движок: **UE 5.8.4**, зафиксирован на весь период до релиза (решение автора 20.11.2026).
- До лета — только Blueprint; C++ добавляем, когда появится машина мощнее и конкретная причина.
- Предварительный релиз: конец 2029 — начало 2030 года.
- Совместимость с UE6 не является критерием оценки решений.

## Где что лежит

- `docs/research/INDEX.md` — все карточки: статус, решение, дата.
- `docs/research/cards/` — карточки паттернов, по одной на вопрос (шаблон: `_template.md`).
- `docs/research/sources.md` — изученные проекты и документы: ссылка, версия движка, лицензия.
